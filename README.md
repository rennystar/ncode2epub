# ncode2epub

「小説家になろう」の縦書き PDF を Kindle 向け EPUB に変換する CLI ツール

[English](#english) · [日本語](#日本語) · [한국어](#한국어)

</div>

```bash
git clone https://github.com/rennystar/ncode2epub && cd ncode2epub
npm install
npx ncode2epub
```

## English

Search for a novel, open its page and click 「縦書きPDF」. When the PDF lands in your Downloads folder, ncode2epub turns it into a vertical EPUB with furigana and a cover. Then send it with Send to Kindle.

The one thing you do by hand is the PDF download. The site's terms don't allow tools to fetch it.

How to use: [GUIDE.md](GUIDE.md) · Please read first: [DISCLAIMER.md](DISCLAIMER.md)

## 日本語

作品を検索して、作品ページの「縦書きPDF」を押してください。ダウンロードフォルダに PDF が届くと、ルビと表紙の入った縦書き EPUB に変換します。あとは Send to Kindle で送るだけです。

PDF のダウンロードだけは手作業です。サイトの利用規約で、ツールによる自動取得が禁止されているためです。

使い方：[GUIDE.md](GUIDE.md)（英語）・ご利用前に：[DISCLAIMER.md](DISCLAIMER.md)（英語）

## 한국어

작품을 검색하고 작품 페이지에서 「縦書きPDF」를 누르세요. 다운로드 폴더에 PDF가 들어오면 루비와 표지가 들어간 세로쓰기 EPUB으로 바꿔 줍니다. 그다음 Send to Kindle로 보내면 됩니다.

PDF 다운로드만 직접 해 주세요. 사이트 이용규약에서 도구로 자동으로 받는 것을 금지하고 있습니다.
