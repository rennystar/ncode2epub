# ncode2epub

Official 「縦書きPDF」 of 小説家になろう → vertical EPUB for Kindle.

```bash
git clone https://github.com/rennystar/ncode2epub && cd ncode2epub
npm install
npx ncode2epub
```

Search, open the novel page, and press 「縦書きPDF」 yourself — this tool never downloads from the site. The EPUB appears in `~/Downloads`; send it with Send to Kindle.
